Small, reliable APIs for software that pays for itself.

Forty-seven utilities — search, screenshots, OCR, video downloads, document generation, reference data — over plain HTTP.

Each call is settled on-chain in USDC on Base through the x402 standard. No account, no API key, no monthly plan. Your first five calls are free.

Try it

Pick a tool, adjust the request, run it. The first five calls from your network are free; after that the API returns an invoice you can pay with any x402 wallet.

Integration

    
Everything is one endpoint pattern: POST JSON, get JSON back.
       Unpaid requests return 402 with a signed invoice;
       retry with an X-Payment header and the result comes back.

    

      

        
From curl or any HTTP client

        
curl /x402/paid/search \
  -H 'Content-Type: application/json' \
  -d '{"query":"base usdc","count":3}'

# 200 on free quota; otherwise 402 + PAYMENT-REQUIRED
# pay, then resend with:  -H 'X-Payment: <signed receipt>'

      

      

        
From Claude or another MCP client

        
{
  "mcpServers": {
    "ox402": { "url": "/mcp402/" }
  }
}

        
Listed in the official MCP registry as
           io.github.Hasned-spec/ox402-utils.
           A Python client and LangChain adapter are in the
           repository.

About

    

      ox402 is an independent utility service operated by a small automation practice.
      It exists because agents need boring things done well — look up a record, render a
      document, fetch a price — and most APIs make you open an account to do them.
      Here the payment is the account: every request carries its own settlement,
      verified by the Coinbase x402 facilitator and finalized on Base.

    

      The service runs on a single small server, keeps no personal data, and stores only
      aggregate call counts. If a tool misbehaves, the catalog always reflects live state.
